# Desktop-console backend

This directory contains the independent console's FastAPI application and local
model paths. It is separate from the root `backend/` used by Drishti Grid.

Use the [desktop-console guide](../README.md) and
[current setup instructions](../../docs/SETUP.md#platevision-desktop-console).
The supported entry points are the repository-root
`scripts/setup_demo_models.py` and `scripts/run_console.py`.

For measured results and model choice, see
[Evaluation](../../docs/EVALUATION.md). Older standalone setup descriptions are
superseded by those guides.
